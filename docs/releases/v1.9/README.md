# Version 1.9 Release Archive

**Status:** Shipped

This directory preserves the implementation, investigation, feedback, and
acceptance-testing records collected during the 1.9 release cycle.

## Release Highlights

- Reworked decks into a first-class management flow with deck editing, artwork,
  duplication, sharing, export, and import.
- Added token discovery by importing copied decklists.
- Added the persistent custom-token library and custom artwork workflows.
- Added the Academy Manufactor utility.
- Improved resilient Hive boot and recovery behavior after investigating
  custom-artwork startup failures.
- Addressed Android compatibility and keyboard/modal issues.
- Standardized artwork presentation across tokens and utilities.
- Fixed utility-card swipe-dismiss backgrounds.
