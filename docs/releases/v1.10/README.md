# Version 1.10 Release Archive

**Release:** 1.10.0+18
**Status:** Shipped

This directory preserves the implementation, validation, and release-planning
records for Tripling Season 1.10. The user-facing summary shipped in
`lib/utils/whats_new_content.dart`.

## Release Highlights

- Added the Rules Calculator for token doublers, triplers, replacement effects,
  Academy Manufactor, Chatterfang, and counter modifiers.
- Added the Hare Apparent utility.
- Added the three-tier support/tip-jar system and Collector heart customization.
- Added remote token-database updates between app releases.
- Expanded token-creation confirmation dialogs with complete result breakdowns.
- Improved companion-token artwork handling.
- Added quantity-cap warnings for large token calculations.
- Added the reusable What's New modal and About-screen entry point.
- Fixed Academy Manufactor and Krenko artwork selection/cropping behavior.
